## 🚀 **Quick Start Guide**

### **Single Item Scan (Basic):**
```
1. Click "Camera" tab
2. Point at barcode
3. Beep! ✅ Scanned
4. View results
```

### **Bulk Scan (Advanced):**
```
1. Click "Bulk" tab
2. Enable "Continuous ON"
3. Scan item 1 → Added ✅
4. Scan item 2 → Added ✅
5. Scan item 3 → Added ✅
6. Click "Export" → CSV downloaded
```

### **Dark Environment:**
```
1. Start camera mode
2. Click "Flash" button
3. LED turns ON 🔦
4. Scan in darkness
5. Toggle off when done
```

## 🎯 **Best Practices**

### **✅ DO:**
- Use bulk mode for receiving/audits
- Export CSV after each session
- Enable flash in dark areas
- Use continuous mode for speed
- Toggle sound based on environment
- Switch to manual if camera fails

### **❌ DON'T:**
- Leave flash ON when not needed (battery)
- Forget to export bulk scans (data lost on refresh)
- Use continuous mode for single items (battery waste)
- Keep camera on when not scanning (privacy)

## 🔐 **Privacy & Security**

### **What We Access:**
- ✅ Camera (for scanning only)
- ✅ Microphone (NEVER - sound is generated, not recorded)
- ✅ Vibration API (haptic feedback only)

### **What We Store:**
- ✅ Scan history (localStorage - 10 items max)
- ✅ User preferences (sound/vibration ON/OFF)
- ❌ No images or videos
- ❌ No cloud uploads
- ❌ No tracking or analytics

### **Data Flow:**
```
Scan barcode
  ↓
Extract barcode value
  ↓
Query database
  ↓
Display results
  ↓
Camera feed discarded (never stored)
```

## 🆘 **Quick Troubleshooting**

| Problem | Solution |
|---------|----------|
| Camera won't start | Check permissions, refresh page |
| No sound | Enable sound toggle, check volume |
| No vibration | Desktop doesn't support, mobile only |
| Flash not working | Device may not have LED flash |
| Can't switch camera | Device has only one camera |
| Bulk scans disappeared | Refresh cleared them, export first |
| CSV won't download | Check browser download settings |
